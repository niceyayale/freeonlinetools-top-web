# FreeOnlineTools.top - Browser-based Utilities

> 浏览器端在线工具集（文本 / 编码 / 哈希）

Browser-based text, encoding and hashing utilities that never send your data to a server

## Features

- Text diff, case conversion and cleanup tools
- Hex, Base64 and URL encode/decode
- Hash and checksum calculators
- Regex tester and JSON utilities
- Everything runs locally - no file upload required

## Tech Stack

`Web Tools` `Text Processing` `Encoding` `Hashing` `Browser-based`
